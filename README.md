# 🤖 AutoReply — Frontend

Frontend dashboard for the WhatsApp auto-reply and CRM platform, built with **Next.js**.

## Features

- **Inbox UI** — real-time conversation view with chat actions
- **Contacts & CRM** — contact list, merge, and team assignment
- **Campaign Management** — create and monitor broadcast campaigns
- **Analytics** — dashboard with filterable charts
- **Responsive Design** — mobile-friendly layout

## Tech Stack

- **Framework:** Next.js, React
- **Styling:** Tailwind CSS
- **State:** React hooks

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```
